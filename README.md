# ✦ AURORA — Creative Digital Experience Agency

AURORA is a modern and creative digital agency website designed to showcase beautiful digital experiences through creativity, innovation, and modern web design.

## 🌐 About The Project

AURORA is a fictional creative digital agency website built with a modern, elegant, and futuristic design. It features smooth animations, glowing visual elements, glassmorphism effects, and a responsive layout.

## ✨ Features

- Modern and premium UI design
- Fully responsive layout
- Smooth animations and transitions
- Glassmorphism effects
- Interactive hover effects
- Creative service showcase
- Portfolio and project showcase
- Testimonials section
- Contact form interface
- Modern footer design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Sections

- Home
- About
- Services
- Why Choose Us
- Our Work
- Testimonials
- Contact

## 🎨 Design Style

- Dark futuristic theme
- Purple and blue gradients
- Glassmorphism elements
- Modern typography
- Creative visual effects
